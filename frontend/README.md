# Frontend — Age Guesser

This folder contains the **Next.js** frontend for the Age Guesser app.

For full project documentation (setup, model details, architecture, and how to run), see the [root README](../README.md).

## Quick start

```bash
npm install
# set your API URL
echo "NEXT_PUBLIC_API_URL=http://127.0.0.1:8000" > .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
